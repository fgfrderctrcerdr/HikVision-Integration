# Verifix — HikVision Integration

Второй концепт-проект (рядом с `Mock-Stand`) — инструкция по интеграции
Verifix с устройствами HikVision.

**Текущий статус:** первый шаг — статичная страница «Устройства»,
визуально повторяющая реальный экран Verifix. Дальше по плану —
превратить в пошаговый гид по интеграции (по аналогии с тем, как
Mock-Stand вырос из статичных страниц в полноценный тур).

## Стек
FastAPI + Jinja2 (тот же, что у Mock-Stand — без сборки, без SPA).

## Локальный запуск
```
pip install -r requirements.txt
uvicorn main:app --reload
```
Открыть http://127.0.0.1:8000/

## Данные
Все устройства на странице — сгенерированные примеры (не боевые данные
клиентов Verifix), созданы для наглядности макета.
