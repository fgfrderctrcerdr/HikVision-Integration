Как узнать серийный номер устройства

Два шага: сначала найдите IP-адрес устройства на самом устройстве, потом откройте по этому адресу веб-панель устройства в браузере — там серийный номер виден в настройках.

Шаг 1 — Находим IP-адрес

  1. 1. Войдите в меню администратора

    Сначала проведите пальцем по экрану устройства (влево-вправо), чтобы разблокировать его. Затем введите пароль администратора — тот, что был задан при первичной настройке устройства.

    Проведите по экрану
    Введите пароль

  2. 2. Откройте раздел «Связь»

    В главном меню устройства найдите иконку «Связь» (значок роутера) и нажмите на неё.

    Меню
    👤Пользователь
    🔒ACS
    🕐Рабочее время
    📶Связь
    ⚙️Базовые
    👁️Биометрия
    📊Данные
    🔧Обслуж.

  3. 3. Выберите тип подключения

    Откроется экран «Обмен данными» со списком: Проводная сеть, Wi-Fi, RS-485, ISUP, Hik-Connect.

    • Устройство подключено по кабелю (LAN) — нажмите «Проводная сеть».
    • Устройство подключено по Wi-Fi — нажмите «Wi-Fi» и переходите к шагу 4.

    Если выбрали «Проводная сеть» — шаг 4 пропускается, экран с параметрами (шаг 5) откроется сразу.

    ‹ Обмен данными
    Проводная сеть если LAN
    Wi-Fi если Wi-Fi
    RS-485
    ISUP
    Hik-Connect

  4. 4. Только для Wi-Fi: выберите текущую сеть

    В списке сетей найдите ту, что отмечена галочкой слева от названия — это значит, что устройство сейчас подключено именно к ней. Нажмите на неё.

    ‹ Wi-Fi
    ✓ Verifix_2.4
    banerma
    Promomed_UZ
    IZZY

  5. 5. Посмотрите IP-адрес

    Откроется экран с параметрами сети. Нужное значение — в строке «IP-адрес». Его понадобится ввести в браузере на шаге 2.

    ‹ Verifix_2.4
    DHCP Вкл
    IP-адрес 192.168.11.99
    Маска подсети 255.255.255.0
    Шлюз по умолч. 192.168.11.1

Шаг 2 — Открываем админ-панель в браузере и ищем серийный номер

  1. 1. Откройте IP-адрес устройства в браузере

    На любом компьютере в той же сети введите в адресную строку IP-адрес, который вы нашли на шаге 1 (например, 192.168.11.64). Откроется страница входа в веб-панель устройства.

    192.168.11.64
    HIKVISION
    Добро пожаловать
    admin
    ••••••••
    Вход

  2. 2. Войдите под администратором

    Логин — обычно admin, пароль — тот же, что вы задавали на самом устройстве при первичной настройке. Нажмите «Вход».

  3. 3. Откройте «Конфигурация» → «Система» → «Системные настройки»

    Слева — узкая колонка иконок, нажмите на значок шестерёнки («Конфигурация»). В открывшемся меню — раздел «Система», в нём — «Системные настройки».

    На вкладке «Базовая информация» (открывается по умолчанию) — строка «Серийный номер». Скопируйте значение и вставьте в поле формы Verifix.

Шаг 1 — Находим IP-адрес

  1. 1. Войдите в меню администратора

    Введите пароль администратора на экране устройства — тот, что был задан при первичной настройке.

    Login
    DAHUA

  2. 2. Откройте «Communication Settings» → «Network»

    В главном меню устройства (значок дома вверху слева открывает его) найдите «Communication Settings», в нём — «Network».

    Main Menu
    👤User Mngmt

    🕐Attendance
    📡Communication

  3. 3. Откройте «Wi-Fi» (или «Wired», если по кабелю)

    Внутри «Network» — список подключений, откройте актуальное для вашего устройства.

    Communication Settings
    Network
    RS-485 Settings
    Wiegand Settings
    DAHUA

  4. 4. Посмотрите IP Address

    На экране Wi-Fi — строка «IP Address». Его понадобится ввести в браузере на шаге 2.

  1. 1. Откройте IP-адрес устройства в браузере и войдите

    Введите IP-адрес (например, 192.168.11.45) в адресную строку. Логин — обычно admin, пароль — тот же, что на самом устройстве.

    192.168.11.45
    admin

    Login

    Слева в списке разделов — «Maintenance Center» (значок гаечного ключа), в нём «System Info» → «Version».
